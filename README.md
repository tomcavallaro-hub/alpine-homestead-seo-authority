## Content rules
- Plain HTML; no JavaScript needed to read any page (JSON-LD only).
- No prices, availability, reviews, or distances other than those published by the host or official sources, with attribution.
- Property facts sourced from thealpinehomestead.com and the official booking listing; local facts from Gore Mountain, American Whitewater, NY State tourism and outfitter sites.
